# Opa
Essas são as minhas configs, eu uso voidlinux com swayfx, me parece ser bem estruturado e estavel.

O motivo de eu estar usando o rofi e o wofi ao mesmo tempo e por causa de um problema que eu venho tendo com a detecção de executaveis e png do wofi.

Eu tenho uma lockscreen feita usando o gtkloock, ainda estou terminando de polir ela para adicionar.

Isso e mais um backup do meu sistema, se esta vendo isso saiba que este usuario esta aprendendo, ja tinha alguma experiencia com Ubunto 24 e 18, so recentemente entrei no Void.

Tentei hyprland antes de começar com sway, obviamente desistir pois esses problemas de repositorio, mesmo usando o hypr-void a incopatibilidade e muito grande.

Se voce esta aqui sabe muito bem o que tem que fazer com esses arquivos não tem porque tutorial a essa altura....

Mas obiviamente caso voce esteja perdido, isso aqui não e um projeto que e bem conhecido como "ricing" que e basicamente costumizar extremamente o linux, para isso e necessario algumas coisas:

WM: E o seu window manager ele e quem define como as janelas do seu sistema são abertas, no meu caso eu escolhi sway.

Waybar: Aquela barra que fica na parte de baixo no windows e mac, no meu caso eu uso duas, o rofi(como launcher) e o wofi(como waybar).

Lockscreen: Sua tela de bloqueio no meu caso eu uso a gtklock, mas ainda estou finalizando ela.

File manager: No meu caso o thunar

Notificador: Em progresso....

Editor de texto: Usando ate mesmo para programar o meu nvim(ainda vou fazer um upload das minhas configurações tambem)

Obviamente tem o OS, no meu caso o Voidlinux
